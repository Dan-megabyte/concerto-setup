
# The Concerto-Setup Repo

A frustrating explanation of server maintenance procedures and the exploration of an
unmaintained system. A tale of two servers, or whatever you want to call it.

On a more serious note, the improvement of the current Concerto setup @ RPI.

For future maintainers, I recommend reading through [the server documentation](./on-site/server-content-docs.md)
and if you have time, the [weekly/daily summaries](./on-site/site-day-one.md).

Other things contained in this repo are the [autorefresh script](./autorefresh/) made
so that Concerto refreshes the feed on a regular interval and the [python fast api server](./python-weather-feed/)
made to adapt and format the openweather api to a feed-like format that Concerto understands.
